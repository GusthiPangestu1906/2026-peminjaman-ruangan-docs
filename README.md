# 📚 Central Documentation: Proyek PdBL 2026

Selamat datang di repositori dokumentasi pusat untuk **Sistem Peminjaman Ruangan Terintegrasi**. Repositori ini berfungsi sebagai acuan utama yang menjelaskan seluruh ekosistem proyek, mulai dari arsitektur hingga panduan teknis pengembangan.

---

## 🚀 Ekosistem Proyek
Proyek ini terdiri dari beberapa repositori yang saling terintegrasi:
* **[Backend API](https://github.com/GusthiPangestu1906/2026-peminjaman-ruangan-backend)**: Dibangun dengan ASP.NET Core 10.
* **[Web Admin](https://github.com/GusthiPangestu1906/2026-peminjaman-ruangan-frontend)**: Dibangun dengan React & TypeScript.
* **[Mobile App](https://github.com/GusthiPangestu1906/2026-peminjaman-ruangan-mobile)**: Dibangun dengan Flutter.

---

## 📂 Struktur Dokumentasi
Di dalam repositori ini, Anda dapat menemukan informasi mendalam mengenai:

### 1. [Studi Kasus](./Documentation.md#1-studi-kasus)
Penjelasan mengenai masalah nyata yang diselesaikan dan solusi digital yang ditawarkan oleh sistem ini.

### 2. [Arsitektur Sistem](./Documentation.md#2-arsitektur-sistem)
Visualisasi diagram Client-Server serta daftar teknologi (tech stack) yang digunakan pada seluruh lini pengembangan.

### 3. [Spesifikasi API](./Documentation.md#3-api-specification)
Ringkasan endpoint REST API yang menghubungkan aplikasi frontend dengan backend server.

### 4. [Refleksi Teknis](./Documentation.md#4-refleksi-pengembangan)
Catatan mengenai kendala teknis (seperti CORS dan Async Gaps) serta pembelajaran yang didapatkan selama pengerjaan proyek.

---

## 🛠️ Panduan Menjalankan Dokumentasi Lokal
Jika Anda ingin melihat dokumentasi teknis secara interaktif:
1. Jalankan **Backend Server** pada port `5215`.
2. Akses **Swagger UI** melalui browser di alamat:
   `http://localhost:5215/swagger`
